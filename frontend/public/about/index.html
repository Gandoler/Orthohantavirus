Orthohantavirus Monitor

About the project

Orthohantavirus Monitor is a surveillance dashboard for tracking verified hantavirus case aggregates, outbreak reports, and public health news in one map-first interface.

What the site shows

The monitor separates reported case aggregates, outbreak events, and editorially reviewed news updates. The interactive map is a client-side layer, while this page and the public surveillance pages are plain HTML for search indexing and accessibility.
