Data sources

Public sources and confidence levels

The project uses a source-first model: every map point and news item keeps a source label, URL, publication or fetch date, and confidence value.

Current source families

  • CDC: public hantavirus materials and case data.
  • ECDC: European epidemiological reports.
  • WHO Disease Outbreak News: outbreak reports.
  • Manual news: editor-reviewed local updates marked as manual.

Confidence

official is used for primary official publications. official_report_derived means a record was extracted from an official report. secondary_verified is used for reviewed manual updates. modelled and manual_review_required should not enter public headline metrics without additional context.

License

Derived open datasets are published as CC BY 4.0 unless an original source sets stricter terms. Citations should include the original source and access date.

Exports

Public APIs return GeoJSON and JSON for map, statistics, outbreaks, and news.

Validation

Pydantic schemas and contract tests check required fields before publication.
