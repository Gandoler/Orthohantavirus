Orthohantavirus: интерактивный учебник по репе и управлению

Проходи главы сверху вниз. Галочки сохраняются в браузере. Команды можно запускать из корня репозитория, если в главе не указана другая директория.

1. Карта системы

Проект состоит из публичного фронта, двух public API, ingestion job, MinIO/S3 и observability/admin слоя.

frontend
  -> /api/map  -> map-api       -> MinIO public artifacts
  -> /api/news -> news-service  -> official feed + manual news

data-ingestion -> CDC/ECDC/WHO -> raw/normalized/public artifacts

admin domain -> Caddy basic auth -> /admin -> frontend
                                  -> /api/news/v1/admin/* -> news-service
Я понимаю, что ручные новости хранятся отдельно от ingestion и не затираются.
Я понимаю, что наружу должен смотреть только Caddy.

2. Локальный запуск

cp .env.example .env
docker compose up --build
Frontend: http://localhost:5173
Admin UI: http://localhost:5173/admin
Map API: http://localhost:8000
News API: http://localhost:8001
Самопроверка 
curl -f http://localhost:8000/health
curl -f http://localhost:8001/health

3. Данные и ingestion

Ingestion читает официальные источники, пишет raw snapshots, normalized JSONL и public artifacts.

docker compose run --rm data-ingestion python -m services.data_ingestion run-all
Что должно появиться в MinIO
  • public/map/latest/regions.geojson
  • public/map/latest/outbreaks.geojson
  • public/news/latest/feed.json
  • manifests/latest.json
Я запустил ingestion и проверил summary endpoint.

4. Фронт

Публичный экран должен работать как инструмент: новостная лента слева, карта справа, compact controls сверху.

cd frontend
pnpm install
pnpm dev
Критерии качества интерфейса
  • нет декоративных hero-блоков;
  • нет пустой карты при отсутствии WebGL;
  • новости фильтруются по источнику и поиску;
  • текст не ломает кнопки и панели на мобильном viewport.

5. Админка новостей

В production админка открывается на admin-домене. Caddy закрывает домен basic auth и прокидывает backend token.

https://admin.<domain>/admin

Локально введи NEWS_ADMIN_API_TOKEN из .env в поле токена на странице /admin.

Что делает кнопка Publish news
  • создает запись в manual/news/items.json;
  • публичная лента сразу начинает отдавать official + manual;
  • следующий ingestion не удалит ручную запись.
Я создал тестовую новость через /admin.

6. Прод и деплой

Продовый путь описан в runbook, но базовый сценарий такой:

cd /opt/orthohantavirus/repo
SKIP_GIT_PULL=1 ./infra/scripts/deploy.sh
DNS должен резолвиться до VPS, иначе Caddy не сможет получить HTTPS-сертификат.
DNS для текущего домена 
ортхохантавирус.рф        A -> VPS IP
admin.ортхохантавирус.рф  A -> VPS IP

7. Эксплуатация

Статус сервисов

docker compose --env-file .env -f docker-compose.prod.yml ps

Логи

docker compose --env-file .env -f docker-compose.prod.yml logs --tail=100 news-service

Backup MinIO

BACKUP_DIR=/opt/orthohantavirus/backups ./infra/scripts/backup-minio.sh

Свежесть данных

curl -f https://<domain>/api/map/health

9. Релизный сценарий

  1. Проверить git status, не коммитить .env.
  2. Прогнать проверки из главы 8.
  3. Сделать маленькие коммиты по смысловым блокам.
  4. Синхронизировать сервер или сделать pull.
  5. Запустить deploy script.
  6. Проверить public endpoints и admin console.
